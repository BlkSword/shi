# 势 / Shi

> **求之于势，不责于人。**
> —— 《孙子兵法·势篇》

一个关于**无中枢决策系统**的研究框架：不改造个体，只设计环境。

---

## 名字

「势」有两层意思：

- **兵法层**：「求之于势，不责于人」——不要求个体变聪明，而是造出一种态势，让行动自然发生。
- **技术层**：势场（potential field）。系统通过塑造环境中的势能景观来引导行为。

名字本身就是论点：**智能不在个体里，在个体与环境之间的那个界面上。**

## 这个框架是什么

一个用于研究**去中心化集体行为**的仿真框架。它提供：

- **确定性仿真内核**：固定时间步长、可复现随机数、状态哈希。同一个种子跑两次，结果逐位一致。
- **多通道环境场**：个体通过改变环境来间接通信（stigmergy），而不是直接发消息。
- **阈值个体**：个体只感知局部，只在自己阈值被超过时行动。分工从阈值分布中自然涌现，不需要调度器。
- **基准任务**：觅食、任务分配、集体建造。
- **实验工具**：参数扫描、指标采集、结果分析。

## 设计原则

1. **确定性优先**。可复现是研究的地基，不是可选项。
2. **先跑通再抽象**。先写能跑通单一任务的最小版本，再谈通用框架。
3. **只在被证明是瓶颈的地方优化**。Python 起步，Numba 加速热点，Rust 只在必要时介入。
4. **实验日志从第一天开始记**。跑几百组之后你会忘记哪组是什么配置。

## 安装

    pip install -e ".[dev]"

可选依赖：

    pip install -e ".[speed]"      # Numba 加速
    pip install -e ".[plot]"       # 绘图
    pip install -e ".[analysis]"   # 统计分析
