# 协调通道污染：攻击分类学与防御评估

当攻击者能写入你的协调介质时，会发生什么。

## 问题

无中心系统靠**共享介质**（信息素、标记、共享内存、消息板）协调。
介质一旦可被写入，就出现一个新的攻击面：

> 攻击者不需要参与协调，只需要污染介质。

这和拜占庭容错不同——拜占庭假设**节点叛变**（攻击者是参与者），
这里攻击者**不参与，只写环境**。

## 四种攻击

| 攻击 | 机制 | 蜂群里 | 本质 |
|---|---|---|---|
| **拒绝** Denial | 压制信道 | 通信干扰 | **删除**信息 |
| **注入** Injection | 随机位置写假标记 | 假目标 | **伪造**信息 |
| **重放** Replay | 已摧毁目标处重写 | 幽灵目标 | **伪造过期真相** |
| **淹没** Flooding | 高频随机噪声 | 信号干扰 | **稀释**信息 |

## 实验结果

固定：80 架无人机、20 个目标、20 信道、200×200 战场、1500 tick、8 个种子。
基准（无攻击）：**87.5%**

### 分类学对比（同等名义强度）

| 攻击 | 轻度 | 中度 | 重度 |
|---|---|---|---|
| 淹没（4× 预算） | -56.9pp | -64.4pp | -64.4pp |
| 注入 | -25.6pp | -45.0pp | -48.1pp |
| 拒绝 | -18.8pp | -25.6pp | -39.4pp |
| 重放 | -10.6pp | -14.4pp | -10.6pp |

### 等预算对比（每 tick 2 个标记）

| 攻击 | 覆盖率 | 损失 |
|---|---|---|
| 注入 | 43.8% ± 10.9 | **-43.8pp** |
| 淹没 | 45.6% ± 19.4 | **-41.9pp** |
| 拒绝（50% 信道） | 61.9% ± 10.3 | -25.6pp |

**结论修正**：注入和淹没在等预算下**效果相当**（-44 vs -42pp）。
早期观察到的「淹没最强」是预算不对等（4 倍）造成的假象。

### 剂量反应

| 每 tick 标记数 | 注入 | 淹没 |
|---|---|---|
| 1 | -43.8pp | -41.9pp |
| 2 | -43.8pp | -41.9pp |
| 4 | -58.1pp | -56.9pp |
| 8 | -61.3pp | -64.4pp |
| 16 | -58.1pp | -64.4pp |
| 32 | -71.3pp | -65.0pp |

两者都在 **-65pp 左右饱和**，说明协调一旦被破坏到某个程度，
再加大攻击强度收益递减。

## 三个关键发现

### 1. 删除信息 < 伪造信息

**在可比预算下，注入/淹没的伤害是拒绝的 1.7 倍**
（-43.8pp vs -25.6pp）。

机制：

- **拒绝 = 删除**：无人机失去引导，退化为随机搜索。低效，但**不会主动犯错**
- **伪造 = 注入**：无人机被主动引向错误位置，**付出真实的飞行和弹药成本**

**工程含义**：抗干扰和抗欺骗是两个不同的问题。
增加带宽能防干扰，但**不能防欺骗**。

### 2. 重放攻击最弱，且时间混淆不是主因

初版测量重放只造成 -10.6 到 -14.4pp。我怀疑是**时间混淆**：
重放的诱饵必须等目标被摧毁后才出现（约 tick 300），
有效攻击时间只有其他攻击的 2/3。

**做了时间对齐实验**：改用预设的「幽灵位置」，从 tick 0 就开始重放。

| 重放方式 | 覆盖率 | 损失 |
|---|---|---|
| 经典（依赖摧毁事件） | 74.0% ± 9.4 | -11.5pp |
| **时间对齐（幽灵位置）** | **72.0% ± 8.2** | **-13.5pp** |

**时间对齐只解释了 2 个百分点的差距。**

**结论修正**：重放确实比注入弱得多（-13.5pp vs -43.5pp），
这不是时间混淆造成的，而是**机制差异**：

> **固定位置的诱饵只能捕获经过附近的无人机；
> 随机分布的诱饵能捕获任何位置的无人机。**

注入每 tick 在随机位置写标记，无人机在任何地方都能被"勾引"；
重放只在少数固定点写，覆盖面小得多。

**工程含义**：防御重放只需要校验少数已知位置的状态；
防御随机注入需要全通道认证。**后者的成本高得多。**

### 3. 便宜的防御可能比攻击更贵

| 防御 | 攻击下收益 | 无攻击时代价 | 净效果 |
|---|---|---|---|
| **信源认证** | **+45.0pp（恢复 100%）** | 0（不影响真实标记） | **压倒性正收益** |
| 快速衰减 0.99 | +1.9pp（恢复 4%） | -1.9pp | ≈0 |
| 快速衰减 0.95 | +3.1pp（恢复 7%） | **-33.8pp** | **严重负收益** |
| 快速衰减 0.90 | +1.9pp（恢复 4%） | -40.0pp | 严重负收益 |

**这是整个研究最有实践价值的结论：**

> 「把标记寿命缩短」这种显然的抗攻击手段，在无攻击时会损失 34 个百分点，
> 而在攻击下只能恢复 7 个百分点。**净损失 27pp。**

**原因**：假标记和真标记用同一个衰减通道。
缩短衰减同时也在破坏真标记的可用性——而真标记需要活得足够长
（无人机跨场要 200 tick）。

**信源认证是唯一的正解**：它只拒绝假标记，不影响真标记。

## 设计原则

| 威胁 | 有效防御 | 无效/有害防御 |
|---|---|---|
| 拒绝（干扰） | 信道冗余 | — |
| 注入（假标记） | **信源认证** | 缩短标记寿命 |
| 重放 | 目标状态校验 | — |
| 淹没 | 提高信噪比 / 认证 | 缩短标记寿命 |

**核心原则**：**防御必须能区分真假信号，而不是笼统地削弱所有信号。**

## 跨领域映射

同一套数学适用于：

| 场景 | 介质 | 注入攻击 | 有效防御 |
|---|---|---|---|
| 蜂群无人机 | 共享标记场 | 假目标标记 | 标记签名 |
| LLM 多智能体 | 共享记忆/消息板 | 被劫持 agent 写假共识 | 溯源 + 交叉验证 |
| 交通系统 | 路况信号 | 伪造拥堵 | 多源验证 |
| 市场（spoofing） | 订单簿 | 虚假挂单 | 监管 + 异常检测 |

**四个领域研究的是同一个问题，但彼此不引用。**

## 跨域验证：多智能体共享记忆

### 为什么能跨域

当前主流的多智能体 LLM 架构里，agent 通过**共享记忆/消息板**协作：

- 一个 agent 完成子任务，往共享区写「我做完了」
- 其他 agent 读到后不再重复

这就是 stigmergy——和蜂群的共享标记场**结构完全相同**。

于是映射关系是：

| 蜂群 | 多智能体 |
|---|---|
| 假标记 | 被劫持 agent 写假完成记录 |
| 淹没 | 大量无关内容冲淡有效信息 |
| 信源认证 | 条目溯源（谁写的、可验证吗） |
| 交叉验证 | 需要多个独立来源确认 |

### 实验设计与结果

20 个 agent、40 个任务，被劫持的 agent 往共享记忆写「任务已完成」的假记录
（实际没做），其他 agent 读到后跳过该任务。

**攻击强度**：

| 被劫持 agent | 完成率 | 损失 | 假记录数 |
|---|---|---|---|
| 0 / 20 | 100.0% | — | 0 |
| 1 / 20 | 78.8% ± 1.8 | -21.3pp | 1,500 |
| 2 / 20 | 66.2% ± 3.4 | -33.8pp | 3,000 |
| **3 / 20** | **56.5% ± 3.9** | **-43.5pp** | 4,500 |
| 5 / 20 | 40.5% ± 4.0 | -59.5pp | 7,500 |
| 8 / 20 | 25.0% ± 3.3 | -75.0pp | 12,000 |

**15% 的 agent 被劫持，就让系统损失 43.5 个百分点。**

**防御效果**（3 个被劫持，攻击率 100%）：

| 防御 | 完成率 | 相对无防御 | 无攻击时代价 |
|---|---|---|---|
| 无防御 | 56.5% ± 3.9 | — | — |
| **溯源认证** | **100.0%** | **+43.5pp（恢复 100%）** | **0** |
| 交叉验证（需 2 源） | 84.5% ± 3.3 | +28.0pp | 0 |
| 交叉验证（需 3 源） | 95.7% ± 2.1 | +39.2pp | 0 |

### 跨域结论

**蜂群的两个核心结论在多智能体系统里同样成立：**

1. **伪造信息是致命的**——15% 的 agent 被劫持，系统损失 43.5pp
2. **能区分真假的防御才有效**——溯源认证恢复 100%，且零代价

**而且多智能体系统里交叉验证也有效**（蜂群里快速衰减无效）：

| 防御类型 | 蜂群 | 多智能体 |
|---|---|---|
| 溯源认证（区分真假） | ✅ 恢复 100% | ✅ 恢复 100% |
| 交叉验证（区分真假） | 未测 | ✅ 恢复 90% |
| 快速衰减（削弱一切） | ❌ **净损失 27pp** | 不适用 |

**统一解释**：**防御是否有效，取决于它能否区分真假信号，
而不是它削弱了多少信号。**

### 诚实的说明

这个模型用的是**规则 agent**，不是真实 LLM。
它验证的是**结构**（读写共享记忆的模式），不是 LLM 的具体行为。

但要把它变成真实验证，只需要把 agent 的决策函数换成 LLM 调用——
接口是一样的。这是明确可做的下一步。

## 局限

1. **重放有时间混淆**（起点晚于其他攻击），需要控制实验分离
2. **认证是理想化的**：假设 100% 可验证，真实系统有误判率
3. **攻击者是固定策略**，没有对抗性学习或博弈
4. **只有一种介质模型**（信道归属覆盖），没有模拟真实信号叠加
5. **没有测防御的成本**（认证的密钥管理、计算开销）
