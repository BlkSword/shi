# 架构

本文档描述框架的**当前结构**，不涉及开发计划。

## 分层

    ┌─────────────────────────────────────┐
    │  experiments/   实验编排与结果分析    │
    ├─────────────────────────────────────┤
    │  tasks/         基准任务定义          │
    ├─────────────────────────────────────┤
    │  core/          仿真内核              │
    │    engine       主循环（固定 tick）   │
    │    world        多通道环境场          │
    │    agent        阈值个体              │
    │    rng          确定性随机数          │
    │    metrics      指标采集              │
    │    statehash    状态哈希              │
    └─────────────────────────────────────┘

## 确定性保证

框架的可复现性依赖三件事：

1. **固定时间步长**。仿真按逻辑 tick 推进，不依赖真实时间。
2. **独立随机流**。每个个体拥有从主种子派生的独立随机流，避免并行化破坏确定性。
3. **状态哈希**。每 N 个 tick 对世界状态做一次哈希，用于验证两次运行是否逐位一致。

## 环境模型

环境是一个多通道场：

    E = (C, W, D)

- **C** — 通道集合。每个通道存储一种信息（例如威胁、补给、指令）。
- **W** — 写入算子。个体在所在格叠加浓度。
- **D** — 衰减与扩散算子。每 tick 按通道衰减，可选扩散。

个体之间不直接通信，只读写环境。这使得通信成本从 O(n²) 降到 O(n)。

## 个体模型

个体只做三件事：

1. **感知** — 读取所在格及邻域的各通道浓度。
2. **打分** — 对每个候选动作计算效用，效用是通道浓度与权重的组合。
3. **执行** — 选最高分动作；若最高分低于阈值，执行默认行为。

阈值在群体中呈分布，分工由此涌现。

## 数据布局

个体状态使用 SoA（Structure of Arrays）布局而非 AoS，以便 NumPy 与 Numba 高效处理：

    positions_x : float64[n]
    positions_y : float64[n]
    thresholds  : float64[n]
    states      : int8[n]

## 依赖

- 必需：NumPy
- 可选：Numba（加速）、Matplotlib（绘图）、SciPy / pandas（分析）
