# 蜂群协调演示

双击 `index.html` 即可打开，无需服务器、无需构建。

## 内容

五个场景的仿真回放，每 20 tick 一帧：

| 场景 | 说明 | 最终覆盖率 |
|---|---|---|
| 无对抗 | 20 信道，无干扰无诱骗 | 90% |
| 通信干扰 50% | tick 300 起一半信道被压制 | 75% |
| 假标记诱骗 20% | 敌方向信道注入假标记 | 45% |
| 双重对抗 | 干扰 + 假标记同时 | 60% |
| 通信瓶颈 | 只有 2 个信道 | 20% |

## 操作

- 左侧画布：点击场景切换
- 底部：播放/暂停、拖动进度条、调速（0.5×–4×）
- 右侧：实时指标 + 图例

## 视觉含义

| 元素 | 含义 |
|---|---|
| 青色圆点 | 正在攻击的无人机 |
| 灰色圆点 | 搜索中的无人机 |
| 红色方块 | 未受损目标 |
| 橙色方块 | 受损目标（边线加粗表示已发现） |
| 深色方块 | 已摧毁目标 |
| 红色 × | 敌方假标记 |

## 数据来源

`demo_data.js` 由 Rust 生成：

    cd rust
    cargo run --release --bin swarm_trace -p shi-syssim

配置：80 架无人机、20 个目标、200×200 战场、1200 tick、seed=7。
