# 蜂群协调演示

双击 `index.html` 即可打开，无需服务器、无需构建。

## 五个场景

| 场景 | 攻击类型 | 最终覆盖率 |
|---|---|---|
| 无攻击 | — | 90% |
| 拒绝：通信干扰 50% | 删除信息 | 75% |
| **注入：假标记诱骗 20%** | 伪造信息 | **45%** |
| **淹没：高频噪声 8/tick** | 稀释信息 | **35%** |
| 组合：干扰 + 诱骗 | 混合 | 60% |

**注意：淹没攻击（35%）比拒绝（75%）伤害大得多——删除信息不如污染信息。**

## 操作

- 左侧画布：点击右侧场景切换
- 底部：播放/暂停、拖动进度条、调速（0.5×–4×）
- 右侧：实时指标 + 图例

## 视觉含义

| 元素 | 含义 |
|---|---|
| 青色圆点 | 正在攻击的无人机 |
| 灰色圆点 | 搜索中的无人机 |
| 红色方块 | 未受损目标 |
| 橙色方块 | 受损目标（边框加粗 = 已发现） |
| 深色方块 | 已摧毁目标 |
| 红色 × | 敌方假标记 |

## 数据来源

`demo_data.js` 由 Rust 生成：

    cd rust
    cargo run --release --bin swarm_trace -p shi-syssim

配置：80 架无人机、20 个目标、200×200 战场、1200 tick、seed=7。
